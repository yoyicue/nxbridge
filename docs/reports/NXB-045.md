# NXB-045：Switch 触屏输入单会话原型

日期：2026-11-02。状态：完成单会话实验原型；后续产品化见 backlog。执行者：codex。

## 目标与范围

让指定 Android 平板的屏幕虚拟手柄控制 Mac 上的 BOTW 游戏进程，保留按下、释放、双摇杆和多点操作，不把 Mac 的系统键鼠或窗口焦点作为游戏输入通道。本次设备是用户指定的 1402，视频仍由此前已配对的 Sunshine / Moonlight 桌面串流提供。

## 最终变更

- 固定 nxnative 引擎 `b8d16169c5fb7a3c6a936a950e294b1df4680551`、Moonlight Android `b48494cb96bff23d8886c4775cc4f39a1075495d`。在仓库忽略的独立副本上应用 [输入适配器](../../adapters/input/)；用户的原有 NX2Apple 工作副本未改。补丁工具检查版本和被修改目标的干净状态；在临时干净 worktree 应用后，与本次九个适配文件逐字节一致。
- 定制 Moonlight 的触屏输入：Switch 方位的 A / B / X / Y、十字方向、L / R / ZL / ZR、+ / −、左右摇杆；摇杆双击为左 / 右摇杆按下。隐藏与 − 重叠的 Guide，原版的布局调整入口保留。试验包独立应用 ID，显示名 NXBridge Pad，versionCode 316；原版 Moonlight 保留，试验包新配对后再升级也保留配对。
- 触摸状态经明确选择的设备的 USB ADB reverse，进入单个游戏进程的回环 TCP 监听器；随机令牌仅存在本机忽略目录及实验 APK 中。接收器维护独立于物理手柄的状态，游戏读取时合并，短按边沿锁存；断开、无完整有效帧约 1 秒或无效序列时清零。连接顺序、入队等待及屏幕隐藏有对应处理。该令牌是实验路由标识，嵌入 APK，不能视为对同设备其他应用的强安全边界。
- 源码见 `adapters/input/`；行为测试见 `tests/input_receiver_test.py`、`tests/input_sender_test.py`。源树依赖机器上可用的 Android SDK 37、NDK 28.2、AGP 9.1.1；实验构建不覆盖官方应用。

## 验证证据

- `python3 tests/input_receiver_test.py`：5 项通过，覆盖短按锁存、同时状态、四轴、拆包、无效认证、序号重放、断开和超时中和。
- `python3 tests/input_sender_test.py`：通过，验证实际 Java 发送器的 16 位 Switch 按键映射、四轴、按下和释放顺序。
- `make check`：通过项目文档和元数据检查；不代替游戏验证。
- Android 客户端 ARM64 构建成功；使用平板现有 `xpad2 install apk` 安装独立包并升级到 316。通过 Sunshine 完成该实验包配对，恢复桌面串流。Pad 触摸通过 ADB 模拟：A 从标题进入选择存档，继续选择最近存档进入户外；游戏内部采样分别记录到 A 的 1 / 0，以及 + 的 1024 / 0。
- 左摇杆上推和右摇杆右推的连续轴值被游戏读到，释放后均回零。通过 Android 多指事件注入，同时推左摇杆和按 B，游戏采样记录为按钮值 `131074`（左摇杆方向伪键加 B）和正向左摇杆 Y，随后回零；见本机忽略目录 `.nxbridge/input-session/game-input.trace`。此处是合成触摸，不是用户本人手感测试。
- 按住平板 B 期间强制终止实验客户端，游戏采样记录从 2 回到 0；随后升级实验客户端并成功重新建立连接。游戏从独立监听器取输入，不读取系统前台键鼠；浏览器地址栏选中时游戏仍记录到 + 和 B，但未单独证明 macOS 前台应用已经切换，因此不把这次作为完整失焦验收。
- 户外画面及修正后的控件截图在本机忽略目录 `.nxbridge/input-session/final-overlay.png`；本次测试没有采集游戏输入到画面的延迟。

## 结论与限制

Pad 的触控确已通过专用通道到达这一个运行中的游戏进程，屏幕布局覆盖常用 Switch 1 控件；这是 USB ADB 原型，**不是无线 LAN 输入的完成实现**。画面目前仍是整个桌面，不是单独游戏窗口，按钮大小 / 位置和手感待用户实测；不是多会话隔离或容量验证。没有测量端到端延迟、实际平板声音、陀螺仪、震动、Home / 截图或长时间重连。若 ADB 隧道中断，当前客户端不会自动重连，需要恢复 ADB reverse 后重新进入串流。Mac 被遮挡 / 最小化行为仍待测。
