# NXB-120：主动触屏绘制基准对照

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

## 方法

1372 Pad（TALIH-PD2，Android 13）经 Wi-Fi 连接 Mac M4、16 GiB、macOS 26.5，使用合成音画，三次实际协商均为 H.264、1280×720、30 FPS、5 Mbps；不运行游戏。以固定 Moonlight Android 修订 `b48494cb96bff23d8886c4775cc4f39a1075495d` 和 NXBridge 387 源构建仅用于诊断的 388，见 `tests/fixtures/client-draw-pixel-ab.patch`。

顺序为正常绘制 A1、像素基准 B、正常绘制 A2，各采样约 18 秒。B 将每个虚拟控件的 `onDraw` 替换为左上角一个 1×1 不透明矩形，保留布局、命中检测、输入和 `invalidate`。这旨在提供非空显示列表，不是无开销，也不是可正常使用的显示模式；本轮按配置文件切换条件，但没有在采样时独立记录每次 `onDraw` 实际走过的分支。三组各通过 Android `uinput` 触发 18 次 L 按放；合成服务每组记录 18 次对应按下和释放。此方法不代表真实手指和游戏输入到画面。

每组采集应用窗口 `gfxinfo framestats` 的 `IntendedVsync → FrameCompleted`，反映整个应用 UI 帧的调度与完成时间，并非控件绘制 CPU 耗时；同时采集 SurfaceFlinger 视频层呈现时刻。合成画面连续运动，三次起始帧号、温度和网络状况可能不同；每组一次，未随机化，样本量有限。触摸期间周期性读取 SurfaceFlinger，本身存在未量化的测量扰动。

原始 `draw-ab2-pixel-{a1,b,a2}-raw.json`、对应 `-gfx.txt`、分析 JSON 和 `synthetic-ab2.log` 留在本机忽略目录。一次重复执行 B 组分析时，由于输出文件已存在被保护性拒绝；换一个输出文件后分析通过，与既有结果一致。分析脚本过滤无效 UI 帧并检查视频快照间断。

## 恢复

测试中的错误点击打开另一主机的配对提示，没有提交 PIN 或完成配对；关闭诊断应用后按名称进入目标主机。每次退出合成串流后，服务日志报告 `ControlStreamStopped`，随后服务回到空闲；未将该日志记作无故障退出证据。测试结束后恢复原游戏服务，1372 偏好文件按字节恢复一致，临时虚拟输入设备退出。1372 更新到只比 387 增加版本号的正常 389（源码 521 文件比较一致），安装包哈希匹配，DEX 不含诊断开关键；1402 保持 387。未启动游戏，未修改存档。
