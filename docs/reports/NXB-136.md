# NXB-136：日常数据迁移与游戏库恢复

日期：2026-11-11。任务仍在进行中。

## 范围和结果

清理实验目录后，两台 Pad 的游戏配置有缺失的引擎、worker、sandbox 和 OoT 构建引用。本次在本机用户的 Application Support 下建立 `NXBridge/storage`，将已验证的 OoT 构建、ROM 资源链接目标、两个后端的运行时、两路 GameStream 配置及配对状态、六份玩家游戏存档、游戏库元数据和封面迁入持久区域。临时会话工作目录与按玩家 / 游戏隔离的缓存分别位于 `NXBridge/tmp` 和用户的 `Library/Caches/NXBridge`。BOTW / TOTK 的游戏资源、着色器库及部分只读配置仍位于原外部实验数据卷，是当前运行依赖；它们没有迁到本机。用户的原文件、旧配置和迁移前存档均保留。

OoT 使用固定 S2Arm 修订 `93bf8c6cab24934b3fe05af4bc04cba1fec84328`。游戏根及其 ROM 符号链接目标均复制到新位置；全树按相对路径、类型、文件大小和链接目标核对，共约 18.7 万项 ROM 资源匹配。该核对不是全部文件内容的逐字节哈希；同卷 APFS 克隆复制返回成功。启动器升级为支持独立 `DM_CACHE` 后，其准备清单哈希及缓存身份改变：比较确认原 / 新宿主二进制、游戏身份、平台以及除启动器外的准备清单相同，才复制和重新标记缓存。之前记录的 14 个目标管线键仍指向非空归档。该检查不代表这些管线在目标路线中已经实际命中。

BOTW / TOTK 分别从保留的 nxnative 工作副本 `b8d16169c5fb7a3c6a936a950e294b1df4680551` 构建独立宿主，源工作副本的未提交更改保留、其差异记录在本机实验目录；各构建均有 52 条警告。TOTK 使用对应 1.2.1 派生 profile。原保存目录在各自写者锁下复制并哈希核对，切换后以新路径为准。BOTW 的两台玩家作弊配置也分别复制并校验，1402 有两份文件、1372 的目录为空；不改变配置内容。1402 的 OoT 标题测试后有两个持久状态文件相对初始备份发生变化；不能在回退时用旧副本覆盖新进度。备份与活跃数据位于同一物理卷，不是异地或故障隔离备份。

游戏库管理台迁移时更新了失效的 OoT 构建目录，库修订由 3 增至 4；管理 API 返回三款游戏的构建目录可访问和封面存在。两路服务分别保留原配对身份并恢复三款游戏入口。现有服务恢复辅助脚本在本机持久目录内，已分别停止并通过脚本重启两路串流和管理台，检查身份和 API；未实现开机自启、安装器、异常恢复或升级管理，也尚未在重启 Mac 后验收。

## 验证

- 新 OoT 路径在存档及缓存副本下离屏运行约 101 秒、编码 5,663 帧并正常退出；预热命中 1,431 条归档、现编 0，源音频有非零采样；引擎和游戏目录写入探针被 sandbox 拒绝。这是短时功能验证，不是性能测试。
- 1402 和 1372 的 Pad 游戏库均显示三款游戏和封面，OoT 分别在两台 Pad 显示画面、正常退出；两次实际预热均记录命中 1,431 条归档、现编 0。1402 另外分别显示 BOTW 和 TOTK 中文标题菜单并正常退出；未进行读档、实玩、输入、音画同步或速度验收。1372 的 BOTW / TOTK 尚未单独实机启动。
- BOTW / TOTK 先以原存档及各自缓存的隔离副本离屏测试，均显示中文标题菜单并正常退出。BOTW 的该菜单样本音频采样全为零，无法作为音频通过；TOTK 有非零音频采样。TOTK 清单预热报告 1,026 个键不在当前 shader map；在离屏样本与 1402 客户端短测分别出现最长 8.76 秒及 1.34 秒源帧间隔，条件和场景不同，不能比较或宣称性能达标。
- 本机私有原始日志、截图、复制校验、配置及恢复清单位于忽略目录 `.nxbridge/nxb136-migration-20261111/`。游戏和密钥没有进入仓库。

## 当前边界与恢复

运行服务及其配置、存档、配对和管理台目前使用迁移后的持久目录。旧目录是迁移前的历史快照，游玩后不再自动同步；恢复或回退时必须先停止对应会话并在锁下备份和核对**新目录的最新存档、配对与库数据**，不能直接使用旧副本替换。按本机记录核对 PID 和启动时间，不以进程名批量终止。现有辅助启动器不会安装系统服务。

服务未运行时，本机可分别运行 `python3 "$HOME/Library/Application Support/NXBridge/storage/host/1402/start.py"`、`python3 "$HOME/Library/Application Support/NXBridge/storage/host/1372/start.py"` 和 `python3 "$HOME/Library/Application Support/NXBridge/storage/host/library/start.py"`；监听地址、端口和外部游戏资源仍须可用。端口已占用时脚本拒绝启动第二个实例。当前 PID 与本次切换记录见本机忽略目录中的 `restart-checked.json`，PID 随重启变化。

迁移结束时本机可用空间约 10 GiB。旧目录和测试文件未删除；APFS 克隆共享底层数据，删除一个副本释放的空间不能按逻辑大小推算。临时目录的归属登记、活动引用检查、崩溃恢复和安全清理器仍未实现，不能将 `tmp`、缓存或实验目录批量删除。BOTW / TOTK 外部卷的资源仍是必需品；受限空间下未复制到本机。后续需完善并验证清理机制、独立备份恢复以及各游戏的读档与实际游玩，再完成任务验收。
