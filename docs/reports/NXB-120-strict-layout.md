# NXB-120：严格布局文件校验

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

## 实现

客户端 369 在本地当前布局、历史修订和便携导入路径先使用 Android `JsonReader` 的非宽松模式进行有界语法扫描，再交给原有 schema 和几何校验。文件保持 64 KiB 上限，限制嵌套深度和读取值数量，拒绝重复字段（包括转义后同名）、非标准 JSON、无效 UTF-8 和尾随数据。schema / revision 必须是整数，身份和控件 ID 必须是字符串，坐标与摇杆参数必须是实际数值，避免 Android JSON 的字符串数值自动转换。schema 比较使用完整整数宽度，避免大数截断后误判为版本 1。未知字段、控件、几何冲突及必需控件继续走既有校验。

应用自己保存的正常历史布局由标准 JSON 和相应数值类型构成；以前被宽松解析器接受的非标准旧文件现在会被视为无效，不自动转换或覆盖。当前布局无法读取时沿用指纹比较、原文件备份和有效历史预览恢复；历史文件损坏时保留并跳过。超过现有恢复备份上限或无法读取的文件仍不自动恢复。

补丁 `adapters/input/moonlight-strict-layout-369.patch` 应用于固定 Moonlight Android 修订 `b48494cb96bff23d8886c4775cc4f39a1075495d` 的 NXBridge 368 状态。严格语法扫描和类型检查不等于已完成玩家配置层、管理 API 或跨设备适配。
