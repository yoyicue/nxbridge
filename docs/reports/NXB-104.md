# NXB-104：选择自有代码许可证与分发策略

日期：2026-11-03。执行者：Codex。

## 目标与范围

按用户选择，为 NXBridge 自有内容设置 MIT 默认许可，明确第三方代码及现有 GameStream 集成包的边界。没有提交、发布、构建客户端或变更运行服务。

## 最终变更

新增根目录 MIT License；`nxbridge-host`、`nxbridge-media`、`nxbridge-stream` Cargo 包元数据声明 MIT。README 和 [来源清单](../open-source-provenance.md) 说明第三方内容继续遵循其许可，包含上游内容的补丁不能覆盖上游权利。`nxbridge-gamestream` 保留 `GPL-3.0-only` 声明；vendored Moonshine 保留原来的 BSD 和 rgsp-cast GPL 许可文本。MIT 是自有内容默认许可，不代表已完成每项贡献及依赖的权利审核。

任务边界调整：本任务记录所选许可和当前组合的分发策略；NXB-105 在实际发行物存在后复核其中各项依赖、客户端、编解码器及对应源码，不用根许可证或自动扫描结果代替审核。

## 验证证据

- `cargo metadata --locked --offline --no-deps --format-version 1`：host、media、stream 为 MIT；gamestream 仍为 GPL-3.0-only。
- `make check-release`：机械检查最终 150 个候选文件，0 项命中；不证明发行物合规。
- `make check`：43 个 Markdown、40 个任务、JSON 和 Python 语法检查通过；创建本报告前曾因新引用尚不存在而失败，补齐报告后通过。

## 结论与限制

用户已选择 MIT。实际发布之前仍须核实贡献者权利、协议子树后续修改授权、依赖和各二进制实际分发方式及对应源码。根许可证的存在不使第三方内容自动改为 MIT，也不证明可公开发布。

## 恢复与交接

无设备、存档、运行服务或系统设置变更。下一步按 NXB-105 准备实际发布候选并完成逐项复核；真实游戏和客户端的干净构建仍未完成。
