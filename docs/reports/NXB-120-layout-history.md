# NXB-120：布局历史选择与恢复

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

## 实现

在固定 Moonlight Android 修订 `b48494cb96bff23d8886c4775cc4f39a1075495d` 和现有 NXBridge 357 补丁之上，新增 `adapters/input/moonlight-layout-history-359.patch`。编辑器“历史版本”列出当前布局之前通过解析、身份、修订、控件和投影校验的修订；当前文件无法读取时列出有效历史。无效历史跳过但保留。玩家选择后只更新草稿并显示“仅预览”，取消不写入，保存以现有冲突检测和原子写入创建新修订。坏当前文件继续使用 357 的指纹比对、备份及显式恢复流程。

工作台恢复前台时，如果仍处于布局编辑状态，继续抑制外部手柄输入；此修改尚未做实体手柄生命周期验收。备份仍在应用私有目录，坏文件备份导出和损坏文件修复尚未实现；后续 363 增加了有效布局的离线导入和导出，详见 [布局文件交接](NXB-120-layout-transfer.md)；不能直接把无效备份当作有效布局恢复。
