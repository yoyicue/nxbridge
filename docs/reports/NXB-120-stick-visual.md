# NXB-120：浮动摇杆显示大小

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

客户端 381 的“摇杆手感”中增加左右独立的“显示大小（%）”，范围为原显示半径的 60–150%，默认 100%。这只缩放浮动摇杆圆圈和内部指示点，激活区、满量程行程、响应曲线和实际轴输出不跟随改变。编辑预览的矩形表示激活区，示意圈显示可见大小和相对比例；示意位置并非实际激活点，实际浮动摇杆仍从用户的触点出现。候选可撤销、取消或随布局保存。

布局新增 schema 3 保存视觉比例，保留 schema 1 / 2 的读取：旧布局打开、预览不会改写；玩家明确保存才产生新格式修订，旧历史保留。**379 及更早客户端不支持 schema 3**；降级前应备份布局和历史，需要旧版继续使用时应明确恢复兼容的旧格式文件或使用旧版导出，不能直接读取 schema 3。不要将 schema 3 导出文件当作旧版可读。
