# NXB-120：小手候选布局

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

此前“小手紧凑”主要移动方向键与少量菜单 / 肩键，面键组没有缩小。客户端 377 调整候选预设：保留 Switch A/B/X/Y 相对位置，将四个面键按当前基准收紧，每个仍不小于 48 dp，面键相互留 4 dp；`+ / −` 分别靠近对应肩键，并与肩键留 4 dp；方向键仍向上移动。各项按实际窗口安全区约束，候选预览后立即复用保存时的完整布局校验；若出现越界、重叠或目标过小，恢复原编辑草稿并提示，不能把无效候选保存为布局。标准与大屏预设也经过该校验。

这是试用起点，不根据屏幕尺寸声称知道玩家手型。选择预设会改变编辑草稿；只有明确保存才生效。升级不会自动套用，游戏库的控制布局 → 布局预设 → 小手紧凑可选择，玩家可继续调整、试按、取消或保存。
