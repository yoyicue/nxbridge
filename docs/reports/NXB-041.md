# NXB-041：本机游戏库登记与构建绑定

日期：2026-11-03。任务状态以 backlog 为准。

## 范围与实现

在本机管理台增加添加游戏、添加构建、修改游戏名称和为现有构建首次绑定目录。管理界面与 CLI / agent 使用同一版本化 Host API，游戏与构建元数据在本机持久保存。构建 ID 与版本对应的记录保持不可变；重试相同操作不会重复登记，对同一构建重新绑定不同目录会返回冲突。

只接受本机已有的绝对目录并检查其可访问性；路径和游戏数据不进入仓库，API 不返回目录路径。目录可访问不等于文件完整或游戏兼容。此阶段不导入或编译游戏、不删除构建、不启动游戏、不管理存档和会话，逐项能力仍按既有记录保存且默认在卡片上隐藏。

管理服务仍仅绑定本机回环。只有显式开启 catalog-write 并指定已有配置文件才允许修改；请求要求受限 Host、来源和专用请求头。Host 持有文件锁，用版本号拒绝同时编辑覆盖；与磁盘内容不一致时返回冲突。写入使用同目录临时文件、同步文件内容和原子替换；跨断电的目录持久性尚未验证。外部编辑者不参与锁时，不能保证与其同时修改的原子冲突检测，应停止服务后再手动编辑。

## 验证

使用临时游戏库、空目录和两个虚构构建验证登记、路径保护、重试、并发冲突、外部编辑冲突、磁盘重载、来源校验及非本机请求拒绝；临时数据不作为真实游戏兼容性证据。Safari 中对独立测试库实际添加游戏、修改名称和添加第二个构建，重启测试服务后两份构建仍在；测试服务及其独立临时目录已清理。

实际管理台中，通过页面将已有 BOTW 1.9.0 实验条目绑定到已准备好的构建目录，页面显示目录可访问；原游戏目录和存档未更改。原游戏库配置已在忽略目录中备份。相关 Rust 测试、页面测试、make check 和 make check-rust 通过。

## 限制与交接

管理台当前作为本机实验服务运行，PID、配置、备份、日志及启动脚本保存在忽略目录 .nxbridge/dashboard-036/。两路 GameStream 服务未改动。用户可通过游戏库的添加游戏、添加构建、绑定目录及修改名称操作管理本机元数据；移除、构建升级、完整性检查、启动、保存和远程身份仍留待后续正式管理任务。
