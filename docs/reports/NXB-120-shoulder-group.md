# NXB-120：肩键联动

2026-11-09，实验客户端 391 为布局编辑器增加「肩键联动」开关。打开后拖动 ZL / L 或 ZR / R，同侧两键保持相对位置一起移动；两侧独立。移动受安全区和其他按钮碰撞限制；浮动摇杆的激活区域不作为碰撞障碍，肩键移入该区域会占用部分摇杆可触摸空间。试按时联动自动关闭，单键大小调整保持独立。该功能不自动更改已有布局。

两台 Pad 均已安装 391。1372 的未保存草稿中，左肩两键一起移动，右侧不动；撤销恢复原位置，右侧可独立移动，移入面键时被阻止，试按关闭联动。1402 的 BOTW 草稿中，左侧两键各下移 314 像素，右侧不动。两台取消草稿后，1372 BOTW 及 1402 BOTW / TOTK 三份保存布局的 SHA-256 与测试前一致。本轮未运行游戏或修改存档。

同侧移动、边界和碰撞的 Java 测试通过；391 在本机离线构建成功，补丁在独立 390 工作区重放后与构建树对应的 6 个文件一致。构建入口见 [实验客户端构建](../moonlight-experimental-build.md)。升级前 390 APK 分别保存在本机忽略目录 `.nxbridge/controller-120/1402-before-391.apk` 和 `.nxbridge/controller-120/1372-before-391.apk`。

ADB 操作不能证明真实小手握持舒适，也不能证明移动后的摇杆区域足够；需玩家在实际握持和游戏中调整、试按并决定是否保存。实体手柄和长期稳定仍需单独验收。
