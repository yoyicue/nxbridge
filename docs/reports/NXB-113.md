# NXB-113：单游戏入口标题与封面

日期：2026-11-08。任务状态以 backlog 为准。

## 范围与实现

用户希望 1402 上当前游戏入口明确为《旷野之息》，未来《王国之泪》有独立入口。此任务仅配置现有单游戏服务的标题与封面；不创建未实现的第二个可启动入口。GameStream 接入已有的 Moonlight 应用列表和封面协议，不修改 APK。服务游戏模式读取可选 `NXB_APP_TITLE` 和绝对路径 `NXB_APP_BOXART`，封面使用 PNG；没有设置时标题仍为 `NXBridge game`。合成源名称和封面行为不受这些游戏参数影响。

1402 使用 `塞尔达传说：旷野之息 (BOTW)` 作为应用名称。封面来自用户本机游戏资源的现有图标，转换为竖版 PNG 并保存在 `.nxbridge/botw-card/`；游戏图片不放进源码或发布物。现有上游应用 ID 按标题生成；修改名称会产生新 ID，旧卡片缓存或客户端个性化设置可能无法自动跟随。后续多游戏实现需要独立稳定的游戏 ID 和对应的启动、资源、存档路由，不能只增加另一张卡片。
