# NXB-124：1372 的《王国之泪》入口

日期：2026-11-09。任务状态以 backlog 为准。

## 目标与范围

在 1372 现有配对和 BOTW 入口不变的条件下，增加 TOTK 的串流入口。游戏运行于 Mac，Pad 不保存游戏本体。1372 使用独立玩家存档、临时目录和管线缓存。

## 变更及验证

- 1372 原服务空闲且无子进程时，备份启动脚本与 1372 BOTW、1402 TOTK 两份原存档并逐文件校验；以原服务端二进制、端口和配对状态重启，加载本机双游戏配置。BOTW 保留原路径及启动参数；TOTK 使用 1402 已部署的对应构建和引擎，但存档、临时目录及管线缓存单独建立，初始存档为空。
- Pad 1372 上实际显示两张完整封面，TOTK 从游戏库加载；截图 `.nxbridge/experiment-124/1372-dual-game.png`。未更新或卸载 APK。
- 点击 TOTK 后，客户端经历启动页和游戏自身加载，实际看到游戏开场画面；截图 `.nxbridge/experiment-124/1372-totk-frame3.png`。游戏首次启动产生 11 个存档文件。通过客户端返回退出后，服务显示空闲、原会话子进程退出。
- 测试后重新核对 1372 BOTW 的 20 文件、1402 TOTK 的 17 文件，均与测试前备份逐文件 SHA-256 一致；1372 BOTW 玩家布局哈希不变。1402 的服务未重启或修改。
- `make check` 通过：93 个 Markdown 文件、54 项任务、JSON 元数据与 Python 语法；该检查不代表游戏性能验收。

## 限制与交接

这是新玩家进度，未复制 1402 存档。此次只验证入口、首次启动与画面；触屏操作、音频、首次正式存档读写、重连、长期游玩及双设备并发性能未验收。1372 TOTK 尚未保存专属小手布局，可从封面下的齿轮自行调整。TOTK 1.2.1 的既有兼容性限制仍适用，见 NXB-115。

本机原启动脚本和原存档备份在 `.nxbridge/experiment-124/`，玩家 1372 的 TOTK 数据留在其独立目录；当前 1372 服务为新双游戏配置，PID 记录在 `.nxbridge/botw-card/second-pad/service.pid`。回退前应先确认服务空闲、会话与子进程退出，再恢复备份启动脚本；保留新玩家存档。不要用宽泛进程终止方式。
