# NXBridge Pad 布局及 BOTW 语言调整

日期：2026-11-03。原有任务状态不变；该记录描述用户要求的单设备迭代。

## 范围与变更

在固定 Moonlight Android 修订 `b48494cb96bff23d8886c4775cc4f39a1075495d` 的 318 实验版基础上构建并安装 319。触屏画面按 Pad 横屏重新排列：左摇杆位于四向键上方，右侧为 Switch 的 X / Y / A / B 菱形及下方右摇杆；肩键和菜单键位于上方。四向键显示箭头，控件有半透明背景和按住时的高亮。保留 Moonlight 原生手柄输入，用户已有的控件位置偏好仍然优先。

可复现补丁为 `adapters/input/moonlight-pad-layout.patch`；`apply_pad_layout.py` 检查上游修订并在既有 318 实验代码上应用。未改动用户原版 Moonlight 或其他游戏。控件的具体尺寸是这台 Pad 的初始布局，舒适度、遮挡和多人手势需用户实际验收；当前仍会覆盖部分游戏 HUD。

原实验启动配置将 BOTW 语言固定为 `en-US`。当前 BOTW 1.9.0 的控制数据包含简体中文，实机 `DM_LANG=zh-CN` 回退日文，而 `DM_LANG=zh-Hans` 显示简体中文标题和菜单。此结果只针对该实验构建，不推断其他游戏的语言代码。

## 验证与交接

离线 Gradle `:app:assembleNonRootDebug` 构建成功，使用平板现有的 xpad2 受管安装路径升级成功，安装后版本号为 319。独立副本应用补丁后与构建源码一致。Pad 为 2560×1600 横屏，实机截图确认布局、中文标题与存档菜单；四个方向键分别观察到游戏输入按下和释放，上方向按住时截图确认高亮；A 用于加载最近隔离存档并进入户外。按键位置和手感尚待用户亲手验收，尚未覆盖所有按键与多点组合。

游戏断开前在用户允许下关闭；切换中文前备份了隔离存档。服务当前以中文运行，Pad 已重新连接并加载最近存档；记录时服务 / worker / 游戏 PID 分别为 76356 / 89398 / 89406，操作前重新核对身份。游戏仍写入实验存档副本，切换语言不会同步到原存档。原 318 APK 留在忽略目录作回退；平板临时 APK 和截图已删除。服务与配置按当前实验继续保留。
