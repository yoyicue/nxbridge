# NXB-101：来源与公开前检查

日期：2026-11-03。执行者：Codex。

## 目标与范围

整理公开前已知第三方来源与授权边界，并建立不涉及游戏、存档、密钥或设备的候选文件检查。没有决定 NXBridge 自有代码的许可证。

## 最终变更

[来源清单](../open-source-provenance.md) 记录锁定版本、第三方许可、GPL 组合的保守处理、当前无法确认的部分和人工复核事项。新增 `make check-release-content` 与 `make check-release`；后者在未选择根许可证时阻断。拆分发布任务以便在家庭产品流程完成前推进开源基础。

## 验证证据

- `python3 -m unittest discover -s tests -p test_check_release.py`：2 项通过，覆盖路径、私钥、禁止扩展名、符号链接与普通文件。
- `make check-release-content`：141 个 Git 候选，0 项命中；该结果不是完整秘密扫描或法律审查。
- `make check-release`：按预期失败，提示根许可证尚未选择。
- `make check`：通过；38 个 Markdown、36 个任务以及 JSON 和 Python 语法通过项目检查。
- 本机离线 Cargo metadata 仅用于了解 macOS 目标依赖声明；没有核实全部依赖源文件或发行物。FFmpeg 构建配置与本机 Android 源码许可证文本已核对，不代表其他环境。

## 结论与限制

NXBridge 自有代码授权、协议子树后续修改的确切权利和完整二进制依赖审核尚未解决；不能据此宣布可发布。检查规则可能漏报或误报，须审阅实际提交及发行包。完整干净 Mac 构建、游戏 worker 和 Android 客户端复现均未验证。

## 恢复与交接

未启动或停止游戏、服务和设备，没有改动存档或临时系统设置。接下来推进无游戏资源构建与合成自检，并由权利人选择自有代码许可证。
