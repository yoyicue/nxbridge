# NXB-120：摇杆边缘反馈与设备能力

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

客户端 383 在启用“轻触反馈 · 仅本机”时，对浮动摇杆一次触摸内首次达到满输出请求一次 Android 本地轻反馈；停留外圈或退回后再次推到外圈不会重复请求，新的触摸或取消后重新计数。默认设置仍关闭，轴值与触摸映射不变。本地 UI 反馈不改变游戏震动或实体手柄震动设置。实际反馈由设备能力及系统设置决定，应用请求不等于用户一定感受到振动。

外观与反馈设置会根据本机振动器能力显示状态。设备没有振动器时显示“轻触反馈 · 本机没有振动器”，点击不可用项会恢复原勾选值并提示；保存其他外观设置时保留已有的轻触反馈偏好，避免因暂时不可用而覆盖旧配置。
