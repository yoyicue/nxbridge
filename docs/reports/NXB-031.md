# NXB-031：合成源与游戏源共用媒体 ABI

日期：2026-11-02。状态：完成 v1 描述符与租约契约；平台传输和离屏输出仍待实现。执行者：codex。

## 结果

在 `crates/nxbridge-media/` 建立共享 C 头文件与 Rust 类型，明确 128 位会话 ID、运行代次、`CLOCK_MONOTONIC` 纳秒、视频 / PCM 格式、GPU 完成后发布、编码释放、帧池和音频队列上限及异常终止。跨进程 OS 句柄不作为整数或指针序列化；具体平台传输尚未实现。详细语义与 Apple 主来源见 [媒体接口 v1](../media-abi-v1.md)。

修正 backlog 中已废弃的 `host/`、`media/` 范围为现有 Rust crate 路径；NXB-035 继续依赖未完成的 NXB-010。未更改正在运行的 Sunshine、游戏、存档或设备。

## 验证

- `cargo test -p nxbridge-media --offline`：5 项通过，覆盖 C/Rust 布局、缓冲范围 / GPU 完成类型、代次和旧释放、队列上限、在途租约、音频采样时钟和间断。
- `clang -std=c11 -Wall -Wextra -Werror` 编译并运行 `tests/media_abi_layout.c`：C 结构大小与偏移断言通过。
- `make check`、`make check-rust`：完成项目元数据检查与离线 workspace 编译。

以上只证明描述符和内存租约模型；尚未证明实际 XPC / Mach 句柄传递、GPU 完成、VideoToolbox 异步释放或真实音画同步。需要 NXB-032 / NXB-035 分别实测。
