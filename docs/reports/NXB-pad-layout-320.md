# Pad 小手布局、BOTW 1.9.0 金手指与预热试验

日期：2026-11-03。原有任务状态不变；本记录是用户要求的单设备迭代。

## 变更与验证

- NXBridge Pad 320 缩小并收拢左右控制区：缩短摇杆、方向键及右侧面键之间的跨度，肩键和菜单键移近主操作区；保留 Switch 式排列、四向标识和按住高亮。Android 离线构建和设备受管升级成功；Pad 保存过的 319 布局会覆盖默认位置，因此先将其备份到本机忽略目录和 Pad 应用私有目录，再应用 320 默认位置。截图确认实际布局，A 键按下 / 释放经原生 GameStream 到游戏并加载最近存档。其他按键在新位置的真实手感与多点组合仍待用户验收；用户可继续在应用内自定义。
- 用户提供的 BOTW 1.9.0 压缩包内 `CD57B23FA4BBAD65.txt` 与当前运行构建的 Build ID 一致。将文件放入本次隔离实例的金手指目录，建立关闭总开关；没有导入压缩包中原有的开关状态。引擎日志显示识别 12 个条目、0 个开启，检查其代码写入地址均未落入当前 rewriter 的变更范围。这只是文件解析与静态检查，不证明每项效果或安全性；尚未实测或启用任何一项。隔离存档在引入前另行备份。当前无窗口 GameStream 原型没有 Pad 金手指管理界面；启用时需指定项目并单独验证，不能把“关 / off / 一键还原”当普通增强项目自动开启。
- 原运行日志曾出现 455.8 ms 长帧，约 440.1 ms 与新管线及着色器库有关；另有 245.7 ms 长帧中 232.3 ms 与此类工作相关。还有纹理上传相关的长帧，不能把所有卡顿归因于管线。实验配置此前关闭了预热及归档；现为本隔离会话启用先行预热和专用管线归档，全量后台预构建仍关闭。首次预热 2,744 项耗时 6.18 秒，写入约 35 MB 缓存；下一次预热耗时 2.26 秒，其中 1,432 个管线基础来自缓存。Pad 成功连接并进入最近户外存档；未经同场景、同路径前后对照，尚不能声称卡顿已解决或给出性能提升数值。
- `make check` 通过；320 补丁在保存的 318 基线上重放后与安装源码一致。代码补丁为 `adapters/input/moonlight-pad-layout.patch`，应用入口 `apply_pad_layout.py`。布局版本 319 的交接记录见 [前次记录](NXB-pad-layout-319.md)。
