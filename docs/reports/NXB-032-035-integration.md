# NXB-032 / NXB-035：单路接入实验

日期：2026-11-02。任务状态以 backlog 为准；本记录不宣布 NXB-035 或 NXB-037 验收完成。

## 目标与范围

按用户要求，将 035 的真实 nxnative 离屏画面和 PCM 接入 032 Rust GameStream 原型，供已配对的 Android Pad 人工验收。单实例、BOTW、720p / 30 FPS / H.264；使用独立存档副本及独立输入端口。使用受控实验引擎修订 `b8d16169c5fb7a3c6a936a950e294b1df4680551`，未修改用户原有引擎副本。

## 最终变更

Mach worker 将 GPU 完成后的 IOSurface 经 VideoToolbox 编码，通过私有有界通道送给 GameStream；PCM 以本地数据报传递，Opus 和网络分包沿用 032。Moonlight 原生手柄包由本地按会话认证的输入桥转换为游戏输入；ADB 仅用于测试时操作 Pad 界面，游戏输入不依赖 USB。断开会关闭本地输入连接，游戏侧清除按键；会话进程组用于结束自己的 worker 和游戏。

真实连接最初触发 Moonlight FEC 验证崩溃：协议核心使用的默认 Vandermonde 矩阵与 Moonlight nanors 的 Cauchy 矩阵不同。已修正矩阵和接收端使用的冗余分片数量舍入；后续同一调试客户端保持连接并显示户外游戏。编码关键帧携带 SPS/PPS，实验编码器使用约 5 Mbps 目标码率。正式网络丢包、重连和故障恢复验收仍未完成。

## 验证证据

- `make check`、`make check-rust`、`cargo test --workspace --offline` 和 5 项输入接收器测试通过；035 worker 以 `clang -Wall -Wextra -Werror` 构建成功。全新固定修订副本成功应用实验补丁，包括 HID 输入补丁。
- 本机桥接冒烟实验收到 145 帧、5 个 H.264 关键帧、1,053 个 5 ms PCM 块；该启动阶段音频为静音。实际 Pad 会话进入 BOTW 标题画面，触屏 A 的按下 / 释放出现在游戏 HID 跟踪，随后加载隔离存档并显示户外画面。游戏日志显示加载后非静音 PCM；尚未由人确认 Pad 的听感与同步。运行日志和截图在忽略目录 `experiment-035`。
- Pad Moonlight 原设 720p / 60 FPS、10 Mbps；为当前实验改为 720p / 30 FPS，随设置自动调整到 5 Mbps。输入法临时切换后已恢复。

## 结论与限制

当前是供用户验收的实验链路。没有测量端到端延迟、帧率、音画同步、可靠的断线重连或多实例；非静音 PCM 不等于听感通过。worker 的实时 PCM 通道允许满时丢块，掉帧 / 音频丢失、颜色、GPU 与编码器故障处理仍需进一步验证。NXB-035 的正式验收与 NXB-037 的依赖仍未完成；不得将本次体验外推到其他游戏。
