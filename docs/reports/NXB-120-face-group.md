# NXB-120：面键联动移动

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

客户端 378 的布局编辑器增加“面键联动”开关。开启后，拖动 A/B/X/Y 中任意一个会整体移动四个面键，保留各自大小和相对位置；四个控件同时描边提示。整个组受实际安全区限制，并检查设置入口与其他启用的非浮动控件，不能让整组移动到相互冲突的位置。浮动摇杆激活区按原有按键优先规则处理。开启联动自动切到移动模式，切换到大小或试按会关闭联动；未开启时仍可逐个移动。整组一次拖动沿用现有草稿、撤销、取消、保存和历史修订。

当前仅支持面键组移动，组大小调整仍是单键操作，也未提供其他按键分组。联动检查的是命中矩形，不代表不同按键形状或真实手指握持时没有误触。

## 验证

- 1372 在游戏库的 BOTW 布局编辑器中开启联动，拖动一个面键后，四个面键均移动 `−70, +39` px，ZL / ZR 未移动；保存为新修订。继续向右拖动时，四键均移动 `+97, 0` px，最右边界停在安全区 x=2500。一次向肩键方向的拖动使整组均移动 `0, −56` px，在进一步重叠前停止；另一次拖动后撤销并保存，控件几何与原修订一致。数据在本机 `.nxbridge/controller-120/378-before.json`、`378-after.json`、`378-bounded.json`、`378-undo.json`、`378-obstacle.json`。
- 1402 同样验证联动移动 `−70, +39` px，四面键相对位置保留、肩键不动；编辑后取消，已保存文件逐字节不变。两台测试配置及历史均已删除；未启动游戏或改动存档。
- `tests/FaceGroupMovementTest.java` 覆盖组内一致位移、边缘限制、边界接触与障碍拒绝。Moonlight 固定修订 `b48494cb96bff23d8886c4775cc4f39a1075495d` 的 NXBridge 377 源应用 `moonlight-face-group-378.patch` 与构建源逐字节一致；离线构建和工作台无网络出口检查通过。两台已安装相同 378 APK、哈希与构建一致；升级前 APK 在本机 `.nxbridge/controller-120/1372-before-378.apk` 和 `1402-before-378.apk`。

`make check` 通过。实际握持、游戏中编辑的断线及多会话故障仍需验收；此前手柄失焦后首次按下可能被拦截的限制仍存在，见 [生命周期输入记录](NXB-120-lifecycle-input.md)。
