# NXB-115：王国之泪独立构建与多游戏入口

日期：2026-11-08 至 2026-11-09。任务状态以 backlog 为准。

## 目标与范围

在保留 BOTW 构建和存档的前提下，核验用户提供的《王国之泪》资源，建立独立的实验构建与存档，并在同一 GameStream 服务中提供两个游戏入口。本任务验证顺序切换与基本输入；游戏完整兼容、性能、体感、震动、长时间稳定性、完整存档恢复及混合游戏并发另行验证。

## 构建与运行证据

- 通过 XCI 包内元数据确认游戏标题；更新控制数据报告 1.2.1，main build ID 为 `9b4e43650501a4d4489b4bbfdb740f26`。固定引擎修订为 `b8d16169c5fb7a3c6a936a950e294b1df4680551`。上游现有游戏配置针对 1.4.2 / 1.4.3，1.2.1 未登记的固定地址修复不自动生效，本次构建不证明所有玩法兼容。
- 在独立引擎副本应用 `adapters/nxnative/embedded-xci-update.patch`，按 Application / Patch 的内容元数据筛选同一 XCI；缺失、重复或不匹配时拒绝继续。以两个本机符号链接向现有构建脚本提供同一文件；原 XCI 未被修改。合并提取数据为 15.9 GB，派生版本配置识别简体中文；仅此一份 XCI 实测。
- 新编译 host 最初被 macOS 安全检查拦截，旧地址检查错误地把超时写为通过；已清除此标记并提供 `adapters/nxnative/region-check-fail-closed.patch`。用户完成系统放行后，实际运行至 `nnMain`，前 15 秒地址区域在配置范围内；后续游戏过程未测。首次管线预编译同样被拦截并空等超过十小时，核对进程后已停止并保留缓存。
- 重试构建退出码为 0：27,578 个基础着色器均命中缓存；另外重新编译 2,724 个变体。管线预编译处理 23,688 对，其中 23,666 构建成功、22 留待实际绘制，0 失败。使用本机非锁定 Metal 编译器，画面兼容性风险仍存在。
- 90 秒独立离屏探测使用新建 TOTK 存档，worker 正常退出；收到并编码 4,314 帧、源音频有非零样本，记录 4 次音频间断。抽样画面可见游戏开场与中文提示；帧数不是性能验收，音频数据不证明 Pad 听感。

## 游戏入口和 Pad 验证

- 实验性 `NXB_GAME_CATALOG` 按会话应用 ID 选择游戏构建、沙箱、资源和存档；禁止存档及临时目录重叠，清除继承的其他游戏 `DM_` 环境。锁位于存档目录旁，避免引擎原子替换目录后锁失效；旧服务和其他程序不参与此协作锁，异常恢复仍依赖 NXB-060。
- 切换前确认 1402 原服务空闲，备份并逐文件校验 BOTW 与 TOTK 存档；保留原配对身份和服务端口，替换为空闲时加载双入口配置的实验服务。第二台 Pad 的服务未更改。
- 1402 的 Moonlight 实际显示两张卡片；TOTK 的 600×900 竖版图取自 [LaunchBox 游戏图片页](https://gamesdb.launchbox-app.com/games/images/165519-the-legend-of-zelda-tears-of-the-kingdom)，只存本机忽略目录，不随源码或 APK 发布。备份并刷新了该游戏的旧图缓存，未清除其他图片。
- 初次进入 TOTK 时，约 10 秒的客户端首帧等待短于游戏启动，发生两次无视频断线。将两个游戏的 `DM_PSO_PREPARE` 从 `1` 改为 `0`，使管线预热在后台执行，保留各自缓存；这可能影响启动后的卡顿，未测性能。TOTK 后续两次首视频包约 5.7 秒和 7.8 秒；冷启动仍可能超过客户端等待时限。
- 1402 实际显示 TOTK 中文菜单，触屏方向键改变菜单选项，随后恢复为“继续游戏”。退出后切换到 BOTW，实际显示 BOTW 中文菜单并读取其原存档目录；退出后其 20 个文件与切换前备份逐个 SHA-256 一致。随后重新打开 TOTK 并留在中文菜单。该顺序切换不证明并发隔离，也未验证完整游戏存读或实机听感。
- `cargo test --locked -p nxbridge-gamestream`：8 项通过，其中包含目录冲突、路由、环境清理、协作锁及引擎替换存档目录后锁保持独占的测试。`cargo fmt -p nxbridge-gamestream -- --check`、补丁反向检查及 `make check` 通过。

## 状态与交接

当前第一路双游戏服务、TOTK worker 和 host 仍在运行，1402 停在游戏主菜单；具体 PID、启动命令、截图、原始日志、私有配置和校验过的备份见本机忽略目录的 `LOCAL-HANDOFF.txt`。该服务每次只允许一个游戏会话；第二路服务不受本任务更改。重新操作前核对 PID、启动时间和是否有活动存档写者。恢复原单游戏服务时先正常退出 TOTK 并确认进程结束，再按本机交接步骤恢复。

后续需要用户实际玩一段并单独验收声音、画面、操作、首次正式存档和重连；1.2.1 固定地址补丁缺失、后台预热时卡顿、启动首帧超时、异常退出与旧服务不参与锁仍是风险。BOTW 测试不外推到 TOTK，NXB-081 的完整第二游戏及混合并发验收仍未完成。
