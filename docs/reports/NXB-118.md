# NXB-118：游戏启动加载界面

日期：2026-11-09。任务状态以 backlog 为准。执行者：Codex。

## 目标与范围

为 Pad 上连接和启动游戏期间的黑屏提供明确提示。保留已有游戏库、配对、触屏设置及存档；此次实机覆盖 BOTW 启动到标题菜单，不外推其他游戏的启动表现。

## 最终变更

定制 Moonlight 331 在连接开始时显示「正在启动游戏」及可退出按钮，连接建立后显示等待游戏画面的提示。加载期间隐藏虚拟控制器；切换到画面后恢复控制器。连接失败或断线时沿用原有错误提示。启动期间退出会停止连接，避免留下正在连接的会话。

解码器首次渲染回调触发画面检查；部分设备不提供回调时，在首个输出缓冲提交后 500 ms 回退。Android 8.0 及以上在启动阶段定期对视频表面采样 32×18 像素，以便在游戏本身输出纯黑帧时继续显示加载页；检测到可见画面后结束。由于黑画面也可能是游戏刻意显示的内容，采样最多持续首帧后的 8 秒，之后显示游戏画面；Android 8.0 以下不做采样。加载页不能缩短游戏启动时间，也不改变无视频超时规则。

## 验证证据

- 两台 Pad 经 xpad2 受管升级到 331，升级前各自 327 APK 已备份；保留应用数据、配对与控制设置。两台分别启动 BOTW，抽样截图显示加载提示并最终进入中文标题菜单，随后正常退出；触屏控件在画面出现后恢复。第二台在 330 的一次启动中观察到加载页消失后仍有黑色游戏帧；331 的一次抽样中对应等待期间仍显示加载页，随后出现菜单。采样并非连续录像，不作为性能或完全无黑帧证明。
- 1402 在 331 的加载页点击「退出」，返回游戏列表且服务恢复空闲；此前 330 的同一退出流程也通过。1402 在 330 加载时临时关闭 Wi-Fi，观察到连接终止错误提示；之后 Wi-Fi 恢复并重连。331 的网络故障注入未重复，错误处理路径保持一致。
- 两路 BOTW 存档分别在启动前备份，测试后各 20 个文件与备份逐个 SHA-256 一致；两路游戏服务恢复空闲，无本任务游戏 worker 留存。两台旧 APK、截图和私有测试数据在本机忽略目录 `.nxbridge/experiment-118/`。
- `StartupFrameDetectorTest` 覆盖纯黑、少量亮点和可见画面；Android 331 离线 `:app:assembleNonRootDebug` 成功。客户端补丁在固定上游 327 实验树重放，八个文件逐字节一致。`make check` 和 `make check-rust` 通过；这些检查不代表游戏性能达标。

## 结论与限制

已在两台设备验证 BOTW 的启动提示、画面切换与控制器恢复；1402 的取消和 330 断网错误路径也有实机证据。《王国之泪》未在本任务重新启动验收。8 秒上限保护有意的暗场，但游戏长时间输出纯黑时，超时后仍可能看到黑屏；很暗或仅有小面积内容的启动画面也可能被短暂遮挡。加载页不处理连接建立后、游戏游玩过程中的卡顿或黑屏。

## 恢复与交接

Wi-Fi 已恢复，临时设备文件已清理；游戏服务保持运行并处于空闲。原存档和备份均保留。若回退，先确认设备和服务空闲；备份的旧 APK 可供恢复，设备安装策略可能不允许直接降级。图片、游戏、凭据和存档不进入源码提交。
