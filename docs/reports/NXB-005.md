日期：2026-11-02。状态：完成设计更新，任务状态见 [backlog](../../tasks/backlog.json)。执行者：codex。

## 目标与范围

根据用户讨论与更新要求，将 NXBridge 的正式目标调整为直接管理 nxnative、以 Rust 实现 Moonlight / GameStream 兼容服务端，并使游戏画面无需在 Mac 窗口呈现。此次仅修改设计、任务与调研元数据。

## 最终变更

- 更新 [独立服务端设计](../game-session-server.md)，明确产品愿景、协议 / 引擎 / 平台边界、离屏纹理与 PCM、缓冲生命周期和内存证据。
- 新增 [ADR-0002](../decisions/0002-rust-offscreen-server.md)，将 Sunshine 定位为基线与过渡，窗口采集成为可选实验。
- 同步 README、agent 约定、产品 / 架构 / 会话 / 输入 / 验收文档与状态，区分无窗口、无物理显示器、锁屏和未登录能力。
- 固定 Moonshine 调研修订 `79554f853135cbac44502b58093a4eb0f0f5e6f1`，注明 Linux 依赖与 Mac 适配尚未验证。
- 增加 NXB-032 / NXB-035 / NXB-037 / NXB-065，调整后续原生隔离与容量任务依赖；保留 NXB-045 的已完成状态与全部证据。

## 结论与限制

已确定目标路线与分阶段门槛，尚未实现 Rust 服务端、协议移植或离屏输出。长期愿景包括个人入口、独立进度和保留会话的设备切换；跨主机运行中迁移和引擎重写不进入首版。语言选择不作为性能收益证据，并发容量保持 unknown。
