# NXB-102：无游戏资源构建与合成自检

日期：2026-11-03。执行者：Codex。

## 目标与范围

提供工作区构建入口、无游戏资源的本地合成音画检查，以及隔离源码候选构建；不涉及设备、游戏资源或存档。

## 最终变更

[快速开始](../quickstart-synthetic.md) 说明已验证环境、依赖、构建、自检和排障。`make check-synthetic` 生成短时音画，检查帧变化、提示音与静音，并用 FFmpeg FFV1 / PCM 封装、验证属性和解码。`make check-clean-source` 复制 Git 候选到一次性临时源码树，使用锁文件编译 workspace 并运行自检。设置 `NXB_CARGO_OFFLINE=1` 可对已有缓存执行离线验证。

## 验证证据

- `NXB_CARGO_OFFLINE=1 make check-clean-source`：144 个候选文件隔离复制，完整 workspace 全新 target 编译成功；60 帧和两秒双声道音频经 FFV1 / PCM 编码及解码，结果通过。临时源码、原始数据和编码文件已自动清理。
- 环境为 Apple Silicon M4、macOS 26.5、Rust / Cargo 1.97.0、FFmpeg 8.1.1、Opus 1.6.1；使用现有工具链、原生依赖与 Cargo 缓存。
- `make check`：40 个 Markdown、36 个任务、JSON 和 Python 语法检查通过。
- `cargo test --locked --workspace --offline`：24 项测试通过；`make check-native-media` 通过无设备原生媒体回归。

## 结论与限制

这不是全新 macOS 安装验证，不能证明首次依赖下载成功；测试使用的软件编码不是 GameStream 的 VideoToolbox / Opus 媒体路径。此前真实 Moonlight 合成链路验收见 [NXB-032](NXB-032.md)，本轮未重新验收设备。Rust 版本和原生工具尚未统一锁定；游戏引擎实验补丁、正式 worker 和 Android 客户端仍缺完整公开构建链。

## 恢复与交接

没有修改设备、游戏和存档；检查只清理自己创建的临时目录。后续增加 macOS CI，并在真正的干净环境单独验证首次安装。
