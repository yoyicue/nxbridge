# NXB-116：统一游戏封面标识

日期：2026-11-09。任务状态以 backlog 为准。

## 目标与处理

用户希望 BOTW 和 TOTK 封面标识一致，并明确不编辑图片。因此选用 [LaunchBox BOTW 图片页](https://gamesdb.launchbox-app.com/games/images/79189-the-legend-of-zelda-breath-of-the-wild) 中现成的 600×900 竖版封面，原 PNG 字节直接复制到本机服务使用的封面路径；该图片左上角带 Switch 标识。TOTK 仍使用 NXB-115 中的封面。游戏图片保存在忽略目录中，不进入仓库和 APK；此项不代表获得公开再分发授权。

两路服务引用同一个 BOTW 封面文件。更新前备份了主机旧图，以及两台 Pad 的 BOTW 旧缓存，仅清除这两个明确的缓存条目，保留 TOTK 图片和其他数据。第一台 1402 后续接回 ADB，按相同方式处理。未修改游戏、存档、配对、APK 或服务进程。

## 验证

- 两台 Pad 显示的 BOTW 封面均有 Switch 标识；1402 的 BOTW 与 TOTK 两张卡片均完整显示，标识位于左上角。
- 两台重新下载的 BOTW 图片 SHA-256 均与主机原样复制的 PNG 一致；旧缓存与原主机图片一致，备份留在本机忽略目录。
- UI 截图、原图片及设备缓存备份位于本机忽略目录，不提交游戏美术资源。此次是图片显示验证，未重新进行游戏串流验收。

## 恢复

本机交接文件记录图片来源、旧图和两台旧缓存的位置；恢复时将备份的旧服务器图片原样放回，并逐台备份、清理对应 BOTW 图片缓存后重新打开游戏列表。操作前检查设备序列号及是否正在游玩。
