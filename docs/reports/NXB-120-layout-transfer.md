# NXB-120：布局文件导入与导出

日期：2026-11-09。任务状态以 `tasks/backlog.json` 为准。

## 实现

客户端 363 在游戏库的离线布局编辑器加入“导入布局”和“导出草稿”。游戏内编辑器不会打开系统选择器：现有游戏 Activity 进入后台会停止连接，因此玩家需要先回到游戏库。导出的是当前有效草稿的控件位置、左右浮动摇杆设置和本地界面反馈选项；不包含游戏身份、主机 UUID、游戏存档、配对信息或游戏震动设置。文件的固定身份标识使导入绑定到当前游戏，而不把来源主机身份写进文件。

导入读取上限 64 KiB、严格 UTF-8、检查导出标识及已有布局 schema、必需控件、投影尺寸和冲突；先预览并提示未保存，保存时仍使用现有修订检查和原子写入。安全区钳制后重新校验，失败则恢复原草稿；文件选择期间或后台读取期间草稿发生变化会拒绝应用。选择器建议打开系统下载目录，用户仍可自行选择；系统或其他文件提供方可以忽略建议。选择器停留期间 Activity 重建会尝试按原基准修订恢复草稿，基准发生变化则拒绝自动应用。

补丁 `adapters/input/moonlight-layout-transfer-363.patch` 应用于固定 Moonlight 修订 `b48494cb96bff23d8886c4775cc4f39a1075495d` 上的 NXBridge 359 版本。此方式仍是实验补丁，不代表完整公开构建链已经完成。

## 验证

- 1372 上的实验版 361 使用实际系统文件选择器导出 1,385 字节草稿；读取文件确认身份为固定便携标识，字段只包含 schema、标识、修订、控件和三个本地选项。最初 360 的选择器停在只读图片来源，保存不可用；361 建议下载目录后保存按钮可用，实际写入成功。
- 使用导出的文件构造本次测试文件，将本地淡出选项改为开启：导入后显示仅预览，取消时未创建布局文件；再次导入并保存后，当前游戏修订 1 的淡出选项为开启，身份绑定当前游戏。另一测试文件将 schema 改为未知版本，导入后没有创建布局文件。此检查未覆盖所有非法组合或跨机型布局。
- 选择器前对草稿打开高对比度，选择器在前台时通过 ADB 停止本次后台应用进程，返回后编辑器重建，高对比度仍在草稿中；取消编辑后，存储文件仍为此前的修订 1，且高对比度为关闭。361 在此恢复场景的状态标签误写成导入预览，362 修正为“已恢复之前的草稿”，未改变文件处理逻辑；362 修正提示文字；最终 363 又检查 JSON 末尾不得附加内容。完整往返和进程重建未在 363 重跑。
- `tests/PortableLayoutFileTest.java` 使用实际读取代码验证 64 KiB 边界、超限拒绝、严格 UTF-8 和短读取；离线 Gradle `:app:assembleNonRootDebug` 通过。补丁可在记录的 359 源文件上应用，并逐字节重建七个 363 文件；工作台现有传输隔离静态检查通过。
- 两台 Pad 已安装相同的 363 APK，实际安装哈希与构建产物一致。1372 实测 363 的有效文件进入预览，附加尾随内容的文件没有进入预览或创建布局文件。测试仅使用自己创建的文件和布局，完成后删除这些临时数据；未启动游戏、未修改存档。两路游戏服务空闲。两台先前 359 APK 保存在本机忽略目录 `.nxbridge/controller-120/1402-before-362.apk`、`1372-before-360.apk`。

选择器提供方、跨机型安全区、恶意或不可用提供方、外部读取时并发修改、过程被系统中断等尚需更广泛验证；不能把本次一种平板的结果外推为所有 Android 设备兼容。损坏文件备份仍保存在应用私有目录，尚无备份文件的图形化导出或直接修复。普通编辑期间并非所有可能的系统销毁场景都已验收；本次仅验证选择器等待期间的一次后台进程重建。
