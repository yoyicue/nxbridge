# NXB-130：两台 Pad 的《时之笛》入口

日期：2026-11-10。任务状态以 backlog 为准。

## 目标与变更

把已验证的 S2Arm 游戏构建登记到 Host 游戏库和两台现有 Pad 的 GameStream 配置。游戏包报告程序号 `0400486024DEC000`、内部版本 `131072`；缺少原始 NACP，不能将该数字称为正式发行版本。用户提供的构建与 [NXB-127](NXB-127.md)、[NXB-128](NXB-128.md) 相同。

Host 管理 API 登记游戏和构建，并上传来源于 [Out of Games 包装图](https://outof.games/news/9920-amazon-has-ocarina-of-time-zelda-40th-anniversary-edition-switch-2-more-in-stock/) 的 Switch 2 美版封面。WebP 仅转为原尺寸 PNG 以符合后台接口，不裁切；原图不进入仓库。封面和版本信息由游戏库提供，不嵌入 APK。两个游戏目录复用已验证的 S2Arm 宿主和游戏资源，分别配置独立新玩家存档、临时目录和同构建缓存副本；没有复制测试玩家或另一台 Pad 的游戏进度。

客户端 403 等待首个视频数据包 10 秒，1402 实际两次在 S2Arm 首帧前退出；新版 404 将仅首个视频数据包等待调整为 45 秒，已接收数据后完整帧的 10 秒期限不变。补丁及脚本固定 Moonlight Android 和 moonlight-common-c 的各自上游修订；保留原取消方式与加载界面。45 秒到期、半帧及其他网络故障未做本次实机注入测试。

## 验证与恢复

- Host API 读取确认游戏和封面，封面字节 SHA-256 与版本一致。两台 Pad 的游戏列表均实际显示三张完整封面。首次在 1402 验证出现超时，升级 404 后实际显示《时之笛》开场；1372 先在跨网段连接时未建立 ENet，用户将其连接到与 1402 相同的 Wi-Fi 后，实际显示相同开场。1372 客户端日志记录首包 15.3 秒，支持旧 10 秒限制不足的判断；两次最终会话均经客户端退出，服务子进程结束。
- 两台升级前各备份原签名 403 APK，404 APK 与两台安装文件 SHA-256 一致，签名一致。Moonlight 的全部补丁从固定上游与子模块在另一个工作区重放，404 修改的两个文件与构建树一致；Android 构建联网补齐依赖后通过。`tests/prepare_moonlight_test.py`、`tests/input_lab_transport_test.py`、S2Arm 启动 14 项与输入接收器 20 项通过。
- 执行期间发现旧游戏配置的 nxnative 引擎目录已缺失，原 1402 进程仍在运行但重启加载失败；未改变旧源码工作区，而从其固定修订实验副本构建了 BOTW 与 TOTK 独立宿主，并使用当前输入接收器。两项构建分别有 52 条警告；TOTK 使用 1.2.1 派生 profile 及其着色器表。
- 1402 使用四份原存档的副本和管线缓存副本回归两个重建宿主：BOTW 实际显示中文菜单并观察到方向键改变选项；TOTK 显示中文菜单。第一次 TOTK 回归误用了其他版本的 shader map，记录到缺失 shader 与黑画面；纠正为该构建原有的 1.2.1 profile / shader map 并重新构建后显示正常菜单，不将失败样本计为通过。测试后四份原存档分别 20、17、20、11 文件与备份逐文件哈希一致；原三份 Pad 自定义布局哈希不变。1372 上重建的旧游戏入口未单独启动，其他玩法及长时稳定未回归。
- `make check` 和 `make check-release-content` 通过；检查范围不等于游戏性能验收。截图、备份、私有配置与日志保留在本机忽略目录 `.nxbridge/experiment-130/`。

## 限制与交接

两台日常服务在原配对身份下运行，启动配置分别加载三游戏目录。测试结束后确认游戏会话和子进程退出，输入法恢复为原设定；1372 Wi-Fi 由用户主动切换并保持。新游戏仍为实验后端，游戏速度随呈现帧率变化的风险、首遇长帧、音画同步及并发容量尚未验收。此次只检查串流开场，未验证新玩家完整存读、游戏动作、声音听感或两台同时游玩。用户自定义旧布局保持不变，时之笛使用独立游戏身份和默认布局。

1402 与 1372 的临时重绑试验已撤回，分别恢复原服务地址；失败的重启已修复并完成上述回归。原配置备份留在本机，但原配置指向已缺失引擎，**不能直接回滚**；先确保服务空闲、会话及子进程退出，再核实所需引擎与 shader map 存在后才可使用。新建的双玩家存档为真实玩家目录，后续不得作为临时测试目录清理。
